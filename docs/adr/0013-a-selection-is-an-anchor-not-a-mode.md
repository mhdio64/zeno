# A selection is an anchor, not a mode

A selection is one optional position — the anchor — and the range is always between it and the cursor. That is the whole data structure. It is not a mode, because nothing behaves differently while it exists, and it is not a second cursor, because every motion already knows where it is going: the motion that moves the cursor also extends the selection, and the same `target()` that `Shift+Right` uses is what `Leader v w` uses. Starting a selection is the only new operation, and it is "remember where I am".

The second decision is that the renderer gained a **range**. Painting a highlighted span was the thing `Shift+arrows`, Find and Replace all needed, and it existed nowhere: the renderer could reverse one whole line and nothing else. Putting it in the renderer now means search will hand it a list of ranges rather than growing its own highlighting, and the cell-level test that pins it (selected cells reversed, neighbours not) is the same test search will lean on.

The third is the clipboard. `Ctrl+C`, `Ctrl+X` and `Leader y` all put text on an internal clipboard *and* emit an OSC 52 sequence, so the copy reaches the machine the user is looking at, including over SSH. OSC 52 has no read direction — no terminal answers a query — so paste stays internal: `Ctrl+V` pastes what this editor copied, not what the user copied elsewhere. That is a real limitation and it is stated rather than hidden; a terminal-level paste still arrives as ordinary keystrokes and still works. The payload is capped at 74,000 base64 characters because tmux refuses longer sequences, and a copy past that cap is kept internally with a message saying so instead of being sent and silently dropped.

One boundary came with it: a selection can be larger than the model can edit. `Ctrl+A` on a 39-million-line file is free — selecting is arithmetic — but the keystroke that follows would delete the whole file through the line overlay, which is quadratic (performance finding 8) and would freeze the editor for minutes with no progress. So a command that would edit or copy more than 10,000 lines refuses and says why, in the same spirit as the operator fence in ADR 0012. The limit is a stand-in for the missing piece table, not a product decision: when the model changes, the constant goes away.
